Rainquail

A sprinkler system manager for Android

Rainquail is a private sprinkler system manager built by an individual developer for one household's own use. It shows a photo map of the yard with its sprinkler heads, valve boxes and shutoff, and keeps the home Rain Bird controller's watering programs, zones, catch-cup tests and city watering rules, with watering advice from the local forecast. It is not offered to the public and is not listed in any app store.

Rainquail uses Google Sign-In only to identify the account that owns the yard, and Google Drive only for backups it makes itself.
